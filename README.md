# Ortodont Rashid — сайт

Демо-сайт ортодонтической клиники: брекеты, элайнеры, этапы лечения, цены, запись на приём.
3D-зуб с брекетом, который «ходит» по странице при прокрутке. Статический сайт без сервера приложений и базы данных.

Все данные клиники (телефоны, адрес, цены, врачи) — заглушки, см. [docs/ЗАМЕНИТЬ.md](docs/ЗАМЕНИТЬ.md).

## Структура

```
src/                 сайт — именно это попадает на сервер
  index.html         разметка
  styles.css         стили
  config.js          ДАННЫЕ КЛИНИКИ: врач, телефоны, адрес, цены
  js/main.js         логика страницы (контакты, цены, форма)
  js/tooth.js        3D-зуб, движущийся при прокрутке (three.js)
  vendor/            three.js 0.160.0 из npm, с контрольными суммами SHA256SUMS
  fonts/             шрифты (OFL), без Google Fonts
  _headers           заголовки защиты для Netlify
deploy/              свой сервер: nginx и инструкция SERVER.md
tools/               сборка, локальный сервер, деплой, проверка живого сайта
tests/               автотесты (node --test)
design/              исходники (логотип), на сайт не попадают
docs/                памятки
.github/             CI/CD и Dependabot
```

## Команды

Нужен Node.js 22+ (для сборки и тестов хватит 20).

| Команда | Что делает |
|---|---|
| `npm ci --ignore-scripts` | установить инструменты разработки |
| `npm start` | открыть сайт локально: http://127.0.0.1:8731 |
| `npm test` | автотесты: файлы, CSP, отсутствие чужих скриптов, целостность библиотек, config.js |
| `npm run lint` | ESLint, html-validate, Stylelint |
| `npm run build` | собрать `dist/` |
| `npm run build:zip` | `dist/` + архив для ручной загрузки на Netlify |
| `npm run check:live -- https://адрес` | проверить опубликованный сайт (заголовки, файлы, закрытые пути) |

На Windows то же самое делают «Открыть сайт локально.cmd» и «Собрать для Netlify.cmd».

## CI/CD

`.github/workflows/ci.yml` на каждый push и pull request: аудит зависимостей → линтеры → тесты →
проверка конфига nginx → сборка. При push в `main` — деплой на сервер по SSH и проверка живого сайта.
Деплой включается после добавления секретов сервера: [deploy/SERVER.md](deploy/SERVER.md).

## Безопасность

- Строгий CSP: скрипты, стили и шрифты только с самого сайта, без встроенного кода; запрет встраивания в чужие страницы.
- Никаких внешних CDN; библиотеки и шрифты лежат в репозитории, целостность three.js проверяется тестом.
- Форма: POST, ловушка для ботов, лимиты длины и частоты; весь ввод выводится через `textContent`.
- nginx: те же заголовки (тест сверяет с `_headers`), лимит запросов с одного IP, только GET/HEAD, TLS 1.2+.
- CI: минимальные права, actions закреплены по SHA, `npm ci --ignore-scripts`, секреты не попадают в pull request из форков.
